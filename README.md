# Corpse Tow

Мод для Project Zomboid Build 42: позволяет связывать и буксировать тела. Исходники включают Lua-код, Java-код, игровые ресурсы и совместимый идентификатор прежнего адаптера Viewpoint.

- [Страница мода в Steam Workshop](https://steamcommunity.com/sharedfiles/filedetails/?id=3823056494)
- [История изменений](CHANGELOG.md)
- `CorpseProxyLab/42/` — Lua-код и игровые ресурсы.
- `CorpseProxyLab/source/` — исходники Java-моста.
- `CorpseProxyViewpoint/` — совместимость со старыми списками модов.

Здесь опубликованы исходники мода; они могут отличаться от версии в Steam Workshop. Для игры используйте сборку из Steam Workshop: скомпилированный Java-мост и инструменты сборки в этот репозиторий не включены. Для работы мода требуется ZombieBuddy с Java-агентом; Viewpoint поддерживается дополнительно.

Условия лицензирования отдельно не указаны.
